سیاست حریم خصوصی کیلس

آخرین به‌روزرسانی: ۴ آبان ۱۴۰۵ (۲۶ اکتبر ۲۰۲۶)

کیلس یک اپ و کیبورد فارسی برای آیفون است که گفتار را بدون اینترنت به متن تبدیل می‌کند. سازنده‌ی کیلس هیچ سروری ندارد و هیچ داده‌ای از شما دریافت نمی‌کند. کیلس تبلیغات، ابزار تحلیل یا ردیابی ندارد و حساب کاربری نمی‌خواهد.

صدا و دیکته

  • صدای شما با مدل گفتاری که روی خود آیفون است به متن تبدیل می‌شود و برای این کار به اینترنت فرستاده نمی‌شود.
  • اپ میکروفون را فقط وقتی باز نگه می‌دارد که «جلسه» را شروع کرده باشید، و هر وقت بخواهید می‌توانید آن را پایان دهید.
  • چند دیکته‌ی آخر فقط در حافظه‌ی موقت اپ نگه داشته می‌شود تا اگر آن را اصلاح کردید، با متن درست جفت شود. این داده با بستن اپ پاک می‌شود.

کیبورد

  • کیبورد برای دیکته به «دسترسی کامل» (Full Access) نیاز دارد، چون متن دیکته را از اپ کیلس روی همین آیفون می‌گیرد. این ارتباط فقط داخل گوشی است (loopback) و از گوشی بیرون نمی‌رود.
  • کیبورد به اینترنت وصل نمی‌شود. آنچه تایپ می‌کنید به جایی فرستاده نمی‌شود.
  • برای پیشنهاد کلمه و بهتر شدن دقت لمس، کیبورد کلمه‌های پرکاربرد شما، جای لمس کلیدها و تنظیمات را فقط روی همین آیفون نگه می‌دارد. با حذف اپ همه پاک می‌شوند و جای لمس‌ها را از تنظیمات اپ هم می‌توانید پاک کنید.

یادگیری از اصلاح‌ها (اختیاری، پیش‌فرض خاموش)

اگر در تنظیمات «ارسال اصلاح‌ها برای آموزش» را روشن کنید و یک توکن GitHub وارد کنید:

  • وقتی متن دیکته‌شده را اصلاح کنید، صدای همان دیکته (حداکثر ۳۰ ثانیه)، متن تشخیص‌داده‌شده، متن اصلاح‌شده و زمان ارسال به مخزن خصوصی GitHub که آن توکن به آن دسترسی دارد فرستاده می‌شود. نام، شماره، مخاطبان، موقعیت یا شناسه‌ی دستگاه فرستاده نمی‌شود.
  • این داده فقط برای آموزش مدل گفتار همان مخزن به کار می‌رود و مدل به‌دست‌آمده از همان مخزن به اپ برمی‌گردد.
  • داده‌ها روی سرورهای GitHub (شرکت GitHub) نگه داشته می‌شوند و تابع سیاست حریم خصوصی GitHub هستند. هر کس به آن مخزن دسترسی داشته باشد می‌تواند آن‌ها را ببیند.
  • توکن فقط در Keychain همین آیفون ذخیره می‌شود.
  • با خاموش کردن این گزینه ارسال متوقف می‌شود. نمونه‌های فرستاده‌شده تا وقتی که آن‌ها را از مخزن پاک نکنید در مخزن می‌مانند.

مدل گفتار

فایل مدل گفتار را خودتان از Files وارد می‌کنید یا، اگر یادگیری از اصلاح‌ها روشن باشد، اپ نسخه‌ی تازه را از همان مخزن GitHub دانلود می‌کند. در این دانلود چیزی جز درخواست فایل و توکن شما فرستاده نمی‌شود.

کودکان

کیلس آگاهانه از هیچ کس، از جمله کودکان، داده جمع نمی‌کند.

تغییرات و تماس

اگر این سیاست تغییر کند، نسخه‌ی تازه در همین صفحه با تاریخ جدید منتشر می‌شود. برای پرسش یا درخواست، در صفحه‌ی Issues پروژه بنویسید.

Keyless Privacy Policy

Last updated: October 26, 2026

Keyless is a Persian app and keyboard for iPhone that turns speech into text without an internet connection. The developer runs no server and receives no data from you. Keyless has no ads, analytics or tracking, and needs no account.

Voice and dictation

  • Your voice is transcribed by a speech model on your iPhone. It is not sent over the internet to do so.
  • The app keeps the microphone open only while you have started a session, and you can end it at any time.
  • The last few dictations are held in the app's memory only, so that a correction you make can be paired with the right text. They are gone when the app closes.

Keyboard

  • The keyboard needs Full Access for dictation because it receives the transcript from the Keyless app on the same iPhone. This connection stays on the device (loopback) and never leaves it.
  • The keyboard does not connect to the internet. Nothing you type is sent anywhere.
  • For word suggestions and touch accuracy, the keyboard keeps your frequent words, where you touch the keys, and your settings on this iPhone only. Deleting the app removes them; touch data can also be reset in the app's settings.

Learning from corrections (optional, off by default)

If you turn on "send corrections for training" in settings and enter a GitHub token:

  • When you correct dictated text, the recording of that dictation (up to 30 seconds), the recognised text, the corrected text and the upload time are sent to the private GitHub repository that the token can write to. No name, phone number, contacts, location or device identifier is sent.
  • This data is used only to train that repository's speech model, which the app then downloads from the same repository.
  • The data is stored on servers of GitHub, Inc. and is subject to the GitHub Privacy Statement. Anyone with access to that repository can read it.
  • The token is stored only in this iPhone's Keychain.
  • Turning the option off stops uploads. Samples already sent stay in the repository until you delete them there.

Speech model

You import the speech model file from Files yourself, or, with learning from corrections on, the app downloads a newer model from the same GitHub repository. Only the file request and your token are sent for this.

Children

Keyless does not knowingly collect data from anyone, including children.

Changes and contact

If this policy changes, the new version is published on this page with a new date. For questions or requests, open an issue on the project's Issues page.
